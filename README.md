# Campus Club Management System

A complete, fully functional, and reproducible full-stack web application for university and collegiate club management. Built with Vanilla HTML5/CSS3/JavaScript (ES6+ Fetch API), Python Flask, and a relational MySQL database with strict Role-Based Access Control (RBAC).

---

## ⚡ 1-Click Launch (Windows)

Simply double-click **[`start_app.bat`](./start_app.bat)** to immediately start the backend server and open the web application in your default browser!

---

All project files are located in [`club-management-system/`](./club-management-system/).
Please refer to [club-management-system/README.md](./club-management-system/README.md) for complete technical documentation, demo account logins, database setup, and REST API details.
